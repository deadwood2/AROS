# AROS Wizard — Macintosh-WB13

Experimental integration in the AROS source tree. This directory is independent of BOINC.

The Macintosh-WB13 theme uses original color values and styling descriptions, not proprietary Apple artwork. The theme configuration is a design specification, not yet a native AROS Appearance theme.

The Windows-side launcher and its WinForms dialogs require migration from the existing launcher source before a runnable build is possible. No native AROS build or Windows runtime test has been completed.

See `themes/Macintosh-WB13/design.json` for the palette. Do not add this directory to AROS build lists until a native executable and its dependencies exist.
